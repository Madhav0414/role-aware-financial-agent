Identity is asserted, not authenticated — a deliberate scope choice, since the requirement is enforcement at the data layer. Every figure and every access decision is computed in Python; the model only phrases the result, and the system answers with no API key at all. Restricted material never enters the prompt, which tests/test_agent.py asserts by inspecting the assembled context rather than the output.
